# Proposed release 1.1.0

Update of the existing `v1.0-CERbot-supplementary` release. Keep that release and its video assets available.

- Add the supplied deterministic classifiers, preprocessing and full Single/hierarchical prompts.
- Add model selection, batch configuration and the fixed selective trusted set.
- Add provider adapter sources and the supplied route mapper.
- Add latest consolidated per-message and per-run exports, external pooling and separate baseline OOF records.
- Add fitted local classifiers, original training/inference code, dependency documentation and provenance.
- Make the existing four synthetic datasets directly accessible without changing their values or ordering.
- Add the current token/state/display helpers and improve the confusion-matrix figures: numerical class order, enlarged fonts, contrasting colors and SVG/PDF/600-dpi PNG export.
- Preserve classification and metric calculations. Remove one commented historical credential from the HTTP-header helper.

This update does not implement missing original helpers, resolve mapper label inconsistencies, conduct new experiments, claim a complete standalone EMS release, or assign a DOI or license. The publication DOI and the software/data DOI are different identifiers.
